# HackoTrack

Find and track hackathons in one place.

## Features
- Search hackathons by name
- Store hackathon details in database
- Simple web interface

## Tech
- FastAPI (backend)
- Streamlit (frontend)
- MySQL (database)

## How to run
1. Clone repo
2. `pip install -r requirements.txt`
3. Update MySQL credentials in `Mysql_db.py`
4. Run: `python main.py` (in one terminal)
5. Run: `streamlit run streamlit_app.py` (in another)
